# Demo walkthrough for the team

All demo records start with the word **DEMO**. Search for DEMO in any list to find them.
When the training is over, run **Actions, Demo data and WhatsApp** with *Delete every DEMO
record* ticked.

## How the pieces connect

    Referrer ──────────────┐ (brings customers, earns a referral fee)
                           ▼
    Lead ── Convert ──► Contact (the consultant)  +  Account (their company)
     │                    │
     │ Service =          ├─► Project ──► Package ──► Timesheets ──┐
     │ Job Support        │      │            (customer pays hours)      │
     │                    │      └─ Freelancer (does the work)           │
     │ Interview Support  ├─► Interview Session ─────────────────────────┤
     │                    │      (type, slot, paid, feedback)            ▼
     │ BGC ── Provider    │                                           Payout
     └─ (fee, status)     │                       (Finance pays Freelancer, Provider, Referrer)
                          └─ panel "Delivery" shows all their projects and sessions

What you see where:

| Open this | You see |
|---|---|
| Contact, tab **Delivery** | Their projects and interview sessions |
| Account, tab **Delivery** | Projects for that company |
| Project | Packages and Payouts |
| Package | Timesheets, hours connected and remaining |
| Freelancer | Projects, timesheets, interview sessions, payouts |
| Provider | Freelancers, BGC leads, payouts |
| Referrer | Leads, payouts, contacts |
| Dashboard (by role) | Manager: Today, Attention (no freelancer, low hours, BGC), Money. Coordinator: Today, Follow up. Interview Manager: Interviews. Finance: Money |

## Try it live (2 minutes each)

- Open the **Money** tab, open the Per Interview payout, use **Select** on Interview
  Sessions, pick the held session, then set the payout to **Paid**.
- Open the Referral Fee payout and set it to **Paid**. The DEMO Dev Patel lead now shows
  *Referral Fee Paid*.
- Open the second Package, set Payment Status to **Paid**, then add a timesheet.

## Phone and WhatsApp

Contact, Lead, Account, Freelancer, Provider and Referrer use the standard **Phone** field.
Click **+** to add more numbers, pick the country, and choose the type: Mobile, Mobile and
WhatsApp, WhatsApp, Office, Home, Fax or Other.
